---
title: "Get component group"
authMethod: "bearer"
api: "GET /api/v1/status-pages/{status_page_id}/component-groups/{id}"
description: "Returns a single component group"
---

Requires `status_pages:read` permission.

<ParamField path="status_page_id" type="string" required>
  Status page UUID
</ParamField>

<ParamField path="id" type="string" required>
  Component group UUID
</ParamField>
