---
title: "Get alert channel"
authMethod: "bearer"
api: "GET /api/v1/alert-channels/{id}"
description: "Returns a single alert channel by ID"
---

Requires `alert_channels:read` permission.

<ParamField path="id" type="string" required>
  Alert channel ID (UUID)
</ParamField>

    "updated_at": "2025-03-01T12:00:00Z"
  }

</ResponseExample>
